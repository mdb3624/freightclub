## CHG-868: Systematic Story ID Collision Audit — US-751–757 Range, US-730 Draft Files, US-704 Missing Row

**Origin:** Follow-on to CHG-867 (2026-09-01), which resolved a single US-754 collision but explicitly flagged — without fixing — that the same pattern likely spanned the whole US-751–757 range. User requested a full audit of all stories for this pattern, with correction. A dedicated research agent read `Story_Map.md` in full, every file in `docs/business/stories/`, and `Story_ID_to_Jira_Mapping.md` to build a complete collision map.

**What was found (2 collision incidents + 1 missing-row gap):**

### 1. US-751–757 range collision (confirmed)
`Story_Map.md`'s Phase 9 "Admin & Intelligence Tools" section used IDs US-751–757 for one set of stories (Dispute Resolution Tools, Platform Health Metrics, Rate Benchmarking, ELD Integration, Document Upload, Freight Insurance, TMS API Access — all `MIGRATION_PENDING`, no story files). Independently, `docs/business/stories/US-751.md` through `US-757.md` (plus Jira FREIG-47–53) documented a completely different, real performance-optimization backlog (Code-Split Auth Module, Lazy-Load Fonts, Replace Zod, [CDN Config — already resolved as US-867 via CHG-867], Replace React Query, Login Hydration, Trucker CPM Calculator) that was never given Story_Map rows at all.

### 2. US-730 collision (three files under one ID)
Beyond the canonical `US-730` Epic (Phase 7a, `COMPLETED`, matches `docs/business/stories/US-730_Carrier_Dashboard_MVP.md`), two more files existed under the same ID with substantively different content:
- `US-730_EarningsLog.md` — already correctly renumbered to **US-730g** via CHG-849 (2026-07-04) *in Story_Map.md*, but the story file itself was never annotated with that renumbering.
- `US-730_Trucker_Dashboard_Redesign.md` — an early planning draft, `READY_FOR_DESIGN`, never given its own ID, never entered Jira, never cataloged in Story_Map.md. Its scope was superseded by the shipped Phase 7a epic + US-730a–h sub-stories.

### 3. US-704 — missing Story_Map row (not a collision)
`docs/business/stories/US-704.md` ("Load Board Analytics & Insights") and Jira FREIG-32 have existed since 2026-04-27, in full agreement with each other, but US-704 had no `Story_Map.md` row at all — same root-cause failure mode (uncataloged at draft time), just hadn't collided with a later ID reuse yet.

**Decision:** Renumber the six colliding performance-backlog stories following the CHG-864/CHG-867 pattern; annotate (don't renumber) the two stale US-730 draft files since their canonical replacements already exist under different, uncolliding IDs; add the missing US-704 row.
