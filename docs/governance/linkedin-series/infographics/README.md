**LinkedIn does not accept SVG for post/article image uploads.** Convert to PNG/JPG before posting:
- Open the `.svg` file in a browser and take a screenshot at the full 1200×630 canvas, or
- Run through any SVG→PNG converter (design tool export, `rsvg-convert`, `inkscape --export-type=png`, etc.)

All text/numbers in these graphics are pulled directly from the corresponding article — no figures invented for the visual.
